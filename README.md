# WardenCrossbow

Скалковый арбалет для Paper 1.21.10.

## Команда

`/wardenbow` — выдать Скалковый арбалет.

## Возможности

- ПКМ выпускает звуковой заряд Вардена.
- Дальность полёта — до 60 блоков.
- При попадании в игрока происходит взрыв силой 4.0.
- Блоки и огонь взрывом не затрагиваются.
- КД — 1 минута 30 секунд.
- КД отображается над хотбаром.
- Стрелы не расходуются.
- Java 21.
- Paper 1.21.10.
